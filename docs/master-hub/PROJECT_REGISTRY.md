## 6. Evidence and Status Policy

Allowed registry statuses include:

- **VERIFIED** — independently confirmed with repository or evidence artifact.
- **PARTIALLY VERIFIED** — some evidence is confirmed, but the complete claim is not.
- **INFERRED** — a relationship or role is reasonably derived from supplied project documentation.
- **PROPOSED** — a future plan or recommendation rather than current fact.
- **UNKNOWN** — no reliable evidence establishes the state.
- **NOT RUN** — an intended test or verification has not been executed.
- **NOT STARTED** — work or implementation is identified but not begun.
- **BLOCKED** — progress cannot proceed until a specific dependency is resolved.
- **REJECTED** — evidence or authority rejects the claim or proposal.

Conservative evidence rules:

2. AiTV is the media and research branch.
3. Triada is the technology and verification branch.
4. Chordloop is the creative products and education branch.
5. HAAI is the guiding philosophy, not a separate agency brand.
6. Human Administrator / Final Authority: Vladimir Kasheev.
7. Unknown is not Verified.
8. A specification is not an implementation.
9. A planned test is not an executed test.
10. A GitHub commit does not prove runtime functionality.
11. Preserve historical evidence and provenance.
12. Never delete or overwrite project records without authorization.

Project information supplied in existing documentation is identified separately from independently verified GitHub facts.
